# 自动化测试平台 - 用户使用手册编写计划

## 一、项目概述

### 1.1 产品定位
轻量级自动化测试管理平台，用于管理和执行远程/本地服务器上的测试脚本，收集测试结果和性能指标。

### 1.2 核心价值
- **零配置部署**：SQLite嵌入式数据库，无需安装数据库服务
- **多步骤编排**：支持复杂测试流程的DAG编排
- **分布式执行**：支持多服务器并行/串行执行
- **实时监控**：WebSocket实时日志推送、WebShell终端
- **结果自动化**：自动解析测试结果，支持判定规则

## 四、编写规范

### 4.1 文档风格
- **语言**：简体中文
- **风格**：简洁明了，操作导向
- **人称**：使用"您"称呼用户
- **格式**：Markdown格式

### 4.2 内容要素
每个功能点需包含：
1. **功能说明**：该功能是什么，解决什么问题
2. **操作步骤**：分步骤的操作指南（配截图）
3. **参数说明**：关键参数/选项的含义
4. **注意事项**：常见问题、限制条件
5. **示例**：典型使用场景

### 4.3 截图规范
- 尺寸：宽度不超过 800px
- 格式：PNG
- 标注：关键区域用红色方框标注
- 文件命名：`功能模块_操作名称_序号.png`
