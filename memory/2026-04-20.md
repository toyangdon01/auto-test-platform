# 2026-04-20 工作日志

## Pipeline YAML 导入导出优化

### 完成的修改

1. **移除冗余的 `serverIds` 字段**
   - `TaskYamlConfig.java` 只保留 `stepServerMapping`
   - 导入时自动从 `stepServerMapping` 提取服务器 ID

2. **优化导出逻辑**
   - 过滤掉自动生成的 `default` stepServerMapping
   - 空对象/空数组不导出（`NON_EMPTY`）
   - 导出脚本名称而非 ID，提高可读性

3. **移除前端自动创建 `default` 步骤**
   - `edit.vue` 不再为无步骤脚本创建默认步骤
   - 无步骤脚本直接提示错误

4. **添加导入模板按钮**
   - 编排列表页面添加"导入模板"按钮
   - 点击下载带详细注释的 YAML 配置模板

### 关键理解

- **stepServerMapping 用途**：每个步骤可以绑定多台服务器并行执行
- **无步骤脚本无意义**：脚本必须定义步骤才能创建任务

- 后端导入导出：`PipelineImportServiceImpl.java`
- DTO 配置：`TaskYamlConfig.java`
- 前端模板下载：`views/pipelines/index.vue`
