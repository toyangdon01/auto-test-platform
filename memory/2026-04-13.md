## 重要限制与注意事项

### 1. 无 Root 权限
- ❌ 无 `sudo`，无法提权
- ❌ 无法访问 `/system`、`/data/data` 下其他应用目录
- ❌ 无法使用 `iptables`、`systemctl` 等系统命令
- ❌ 无法绑定 1024 以下端口

### 2. 文件系统
- ✅ 可写：`$HOME`、`$TMPDIR`、`/sdcard`（如果授权）
- ❌ `/tmp` 不存在！必须用 `$TMPDIR`（指向 `/data/data/com.termux/files/usr/tmp`）
- ❌ 根文件系统只读
- ⚠️ 根分区紧张（仅 309MB），但 Termux 数据在 /data 分区（93GB 可用）

### 3. 包管理
- 用 `pkg` 而非 `apt`（虽然 apt 链接存在）
- 安装命令：`pkg install <package>`
- 搜索：`pkg search <keyword>`

### 4. 平台兼容性
- Python 包：大多数可用，但涉及系统调用的可能失败
- Node.js 包：大多数可用，但原生模块需 Android 兼容
- ❌ Playwright 不支持 Android
- ❌ Docker 不支持
- ❌ 无法运行需要 systemd 的服务

### 5. 网络能力
- ✅ 网络完全可用（TCP/UDP/ICMP）
- ✅ 可以运行服务器（绑定 127.0.0.1 或 0.0.0.0 高端口）
- ✅ 可以 ssh、curl、wget

### 6. 进程与后台
- ⚠️ Android 会杀后台进程，长任务需要 `termux-wake-lock` 或前台运行
- 可用 `nohup` + `&` 但不稳定
- 推荐用 `tmux` 或 `screen` 保持会话

### 7. 特殊路径
- Home: `/data/data/com.termux/files/home`
- Prefix: `/data/data/com.termux/files/usr`
- Temp: `$TMPDIR` (自动设置)
- Storage: `/sdcard`（需 `termux-setup-storage` 授权）

## 浏览器控制研究

### 问题
想让 OpenClaw 在 Termux/Android 环境下操作浏览器。

### 尝试过程

1. **OpenClaw 内置 browser 工具**
   - 依赖 Playwright
   - Playwright 官方不支持 Android (`Error: Unsupported platform: android`)
   - 结果：❌ 无法使用

2. **Python playwright 包**
   - `pip3 install playwright` 返回 `No matching distribution found`
   - Android 不在支持平台列表中
   - 结果：❌ 无法安装

3. **Selenium + 本地 Chromium** ✅
   - Selenium 4.43.0 安装成功
   - Chromium 146 已安装在 `/data/data/com.termux/files/usr/lib/chromium/chrome`
   - chromedriver 在同目录下
   - 测试通过：可以打开网页、获取标题、截图、执行 JS

### 解决方案

创建了 **browser_server.py** - 一个基于 Selenium 的 HTTP 浏览器服务

**路径:** `~/scripts/browser_server.py`

**启动命令:**
```bash
python3 ~/scripts/browser_server.py --http 8765 &
```

**API 端点:**
- `GET /open?url=<url>` - 打开网页
- `GET /title` - 获取当前页面标题和 URL
- `GET /html` - 获取页面源码
- `GET /screenshot?path=<path>` - 截图保存
- `GET /find?selector=<css>` - 查找元素
- `GET /click?selector=<css>` - 点击元素
- `GET /type?selector=<css>&text=<text>` - 输入文本
- `GET /evaluate?js=<code>` - 执行 JavaScript
- `GET /quit` - 关闭浏览器

**注意事项:**
- 某些网站会检测 headless 浏览器触发验证码
- 复杂交互可以用 `evaluate` 执行 JS 绕过
- URL 中的特殊字符需要 URL 编码（如 `#` → `%23`）

### 配置更新

更新了 `openclaw.json` 添加 browser 配置：
```json
"browser": {
  "enabled": true,
  "executablePath": "/data/data/com.termux/files/usr/lib/chromium/chrome",
  "headless": true,
  "noSandbox": true
}
```

但内置工具因 Playwright 限制仍无法使用，需要用 Selenium 方案。

## Android 进程限制解除（重要！）

### 问题
Android 12+ 默认限制每个应用最多 **32 个子进程**，超过会被系统杀死 (Signal 9)。

### 解决方案
使用无线 ADB 解除限制。

### 执行记录
**时间：** 2026-04-13 18:31  
**设备：** 三星 S10 (Android 12)  
**ADB 版本：** 35.0.2

**步骤：**
1. 安装 ADB 工具：`pkg install android-tools`
2. 开启无线调试
3. ADB 配对：`adb pair 192.168.1.4:39137 497775`
4. ADB 连接：`adb connect 192.168.1.4:39317`
5. 解除限制：
   ```bash
   adb shell device_config put activity_manager max_phantom_processes 2147483647
   adb shell device_config set_sync_disabled_for_tests persistent
   ```

**结果：** ✅ 成功，当前限制 2147483647（无限制）

### 重启后恢复
手机重启后设置会失效，需要重新执行：
```bash
~/restore-phantom-fix.sh
# 或手动执行上述 ADB 命令
```

### 相关脚本
- `~/fix-phantom-process.sh` - 自动检测和修复脚本
- `~/restore-phantom-fix.sh` - 重启后恢复脚本
- `~/adb-phantom-fix-guide.md` - 完整指南

### 注意事项
1. 每次重启手机需要重新执行
2. 无线调试端口会变化，需要查看最新端口
3. 配合电池优化白名单、后台保护等使用
